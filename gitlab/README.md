# README Template

This folder contains gitlab templates.
This includes :
- The gitlab workItem templates
- The gitlab Merge Requests templates

# Description

A workItem is a Task description that is used to keep a repository clean and structured.
A Merge Request is the equivalent of a `Pull Request` from github. It the a review request from the other members of a group before merging a branch int another one.

# Usage 

For the WorkItem template, place the `.md` file in the folder `.gitlab/issue_templates` from the root of the repository to allow gitlab to find them.
For the Merge Request template, place the `.md` file in the folder `.gitlab/merge_request_templates` from the root of the repository to allow gitlab to find them.
